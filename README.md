# 巨日禄 AI

## 面向专业短剧与漫剧团队的 AI 影视生产平台

巨日禄 AI 是一套服务于短剧、漫剧及相关视频内容生产的 Web 平台。它将剧本解析、角色与场景资产、分镜制作、镜头生成、智能审片、未达标镜头重抽和剪辑衔接到同一条工作流中，帮助专业内容团队提高规模化生产效率。

## 巨日禄解决什么问题

AI 视频模型越来越多，不同模型擅长的镜头类型、成本和生成质量并不相同。实际生产一部短剧或漫剧时，团队往往需要处理数百个镜头，并反复经历选模型、测试、抽卡、审片和重做。

巨日禄将这些步骤组织成可管理的生产流程：简单镜头优先使用满足质量要求且更具性价比的模型，高难度动作、复杂运镜或多人互动镜头可匹配能力更强的模型；自动化流程同时保留人工查看、修改和确认空间。

## 核心能力

### 本入剧出

提交完整剧本后，平台可沿着剧本拆集、分镜与资产、镜头生成、智能提案及分集管理等环节推进制作。团队可以选择不同制作标准，并在关键节点查看和调整结果。

### 模型路由

系统根据分镜难度、动作幅度、运镜方式、人物数量和表演要求，为不同镜头匹配更适合的生成模型。它的目标不是让所有镜头都使用最高规格模型，而是在视觉效果、制作周期和成本之间取得更合理的平衡。

### 一键成片

巨日禄的一键成片工作流覆盖从剧本输入到分镜和镜头生成的连续流程，适合整集、整部内容的批量制作，而不仅是单个镜头生成。

### 自动审片与自动重抽

平台可对生成镜头进行智能检查，并对未达到要求的镜头继续生成，减少创作者长时间人工盯盘、筛选废片和重复抽卡的工作量。

### 团队资产沉淀

角色、场景、画风和项目素材可在团队工作流中持续积累与复用。团队可以把一部作品中形成的制作经验带到后续项目，而不是每次从零开始。

### 全流程人工可干预

剧本解析、角色与场景设定、分镜、镜头生成、审片及剪辑等关键环节保留人工查看、修改和确认能力，让自动化生产仍然保有创作控制权。

## 典型工作流

1. 输入或上传完整剧本。
2. 解析剧本并拆分剧集。
3. 建立角色、场景和画风等项目资产。
4. 生成并调整分镜。
5. 根据制作标准和镜头难度进行模型路由。
6. 批量生成镜头，自动审片并重抽未达标内容。
7. 人工确认关键结果，进入分集管理与成片流程。

## 制作标准

- 旗舰质感：优先追求视觉表现上限，适合高难度动作、复杂运镜和重点镜头。
- 均衡制作：综合考虑质量、制作周期和成本。
- 效率量产：强调稳定产能和整体费效比，适合大批量常规镜头。

具体可用模型、功能、报价与交付方式以巨日禄官网和项目实际配置为准。
