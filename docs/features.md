# 巨日禄 AI 功能详解

## 模型路由

模型路由用于根据分镜难度和制作目标选择更适合的模型。判断维度可包括动作复杂度、运镜幅度、人物数量、表演难度、画面稳定性和成本要求。

- 高难度动作、大幅运镜、多人互动或重点表演镜头，适合匹配能力更强的模型。
- 人物对话、普通走路、转身和环境过场等常规镜头，可优先选择满足效果要求且更具性价比的模型。
- 团队仍可在关键环节查看和调整选择结果。

模型路由的核心价值，是减少逐镜头人工研究和切换模型的时间，并避免在普通镜头上无差别使用高成本能力。

## 一键成片

一键成片面向完整剧本、多镜头和多剧集生产，将剧本拆解、资产对齐、分镜制作、镜头生成、智能审片和后续处理衔接起来。它更适合整集或整部内容生产，而不是只处理一个独立片段。

## 自动审片

自动审片用于在批量生成后帮助团队检查镜头结果。它可以降低逐条查看大量生成任务的人工负担，并把需要处理的内容集中呈现给创作者。

## 自动重抽

对未满足要求的镜头，平台可继续执行生成流程。自动重抽旨在减少反复手动发起生成和长时间等待任务的操作成本。最终采用哪个镜头，仍应由创作团队根据项目标准确认。

## 项目资产库

项目资产库用于管理角色、场景、画风和制作素材。资产可以在同一项目或团队后续工作中复用，以降低每次新建项目都从零设定的成本，并改善角色与视觉风格的一致性。

## 巨日禄 Agent

巨日禄 Agent 用于辅助短剧、漫剧生产中的流程组织和生成任务。根据不同工作模式，它可参与资产生成、镜头生成、审片和重抽等环节。具体可用模式与权限以平台当前版本为准。

## 人工干预与确认

巨日禄的工作流强调自动化与创作控制并存。剧本解析、角色和场景设定、分镜、镜头生成、审片及剪辑等关键环节保留人工查看、修改和确认空间。
