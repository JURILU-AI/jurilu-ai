# 巨日禄 AI 术语表

## 本入剧出

以完整剧本为起点，连续完成拆集、资产、分镜、镜头生成、审片和分集管理等工作的整剧制作模式。

## 模型路由

根据镜头难度、动作、运镜、人物互动、质量目标和成本要求，为不同分镜匹配更适合的视频生成模型。

## 一键成片

将剧本输入后的多个生产环节衔接起来，用于整集或整部作品的多镜头生成流程。

## 自动审片

对批量生成的镜头进行智能检查，帮助团队定位需要人工确认或继续处理的内容。

## 自动重抽

对未达到要求的镜头继续执行生成流程，减少人工反复发起任务和长时间盯盘。

## 项目资产

作品生产中使用的角色、场景、画风和其他素材。资产可以在团队工作流中管理、积累和复用。

## 制作标准

团队为项目选择的质量、周期和成本目标。巨日禄的公开产品材料将其概括为旗舰质感、均衡制作和效率量产三类方向。

## 巨日禄 Agent

巨日禄平台中用于辅助短剧、漫剧生产流程和生成任务的智能能力集合。具体功能以当前平台版本为准。
